# 准时：像素游戏机界面

2026-09-08最新需求：横竖屏均需重新优化，统一游戏像素风；机身边缘、界面和操作都应像游戏机。

- 保留深蓝/金色身份，外层蓝灰机身、硬边阶梯角、内凹屏幕框；页面为同一台设备里的不同屏幕。
- 标题、按钮、字段、列表统一Fusion Pixel；字号以20/30/40等整数档为主，不再sans主导。
- 页面标题置于机身上方；真实返回/取消/新增放在实体按键形区域。屏幕内用细分隔与像素标题条，避免整页普通工具卡片。
- 横屏宽屏机身：概览/日程、内容/时间并排；竖屏掌机：紧凑顶栏、单列屏幕，可滚动而非挤压。
- 所有可交互控件有明确可见的常态边界、选中与按下即时状态，>=48dp；无页面动画。保留原删除两步及确认。
- 不加无作用方向键、不照搬商业游戏机Logo/素材。边框与几何像素图形使用现有Compose Canvas/Border；Kenney CC0 UI Pack只参考通用像素边缘结构。
- 原生时间/日期/声音选择功能保留，逐个检查是否符合整机视觉，不能因换皮损失输入和无障碍。
- 候选12.1尚未正式交付；所有模拟器证据注明API32，不冒充华为实机。

资源约定：res/drawable/仅放当前界面实际引用的XML像素边框；以pixel_前缀命名，不复制旧遗留ids或闲置素材，失去引用时随改动清理。
参考：Kenney Pixel UI资源索引（CC0结构参考，无下载复制）https://kenney.nl/assets?search=ui；Compose绘制官方文档 https://developer.android.com/develop/ui/compose/graphics/draw/modifiers。
